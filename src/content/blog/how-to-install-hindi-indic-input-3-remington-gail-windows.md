If you are preparing for **SSC, UP Police, Allahabad High Court, Bihar BSSC, or Rajasthan High Court** typing tests, learning **Mangal Font (Remington Gail Layout)** is mandatory.

However, many candidates struggle to type Hindi on their Windows PC because Windows does not include the Remington Gail layout by default (it only includes Inscript).

To type in Remington Gail, you must install **Microsoft Hindi Indic Input 3**. In this step-by-step guide, we walk you through the exact download, installation, and configuration process for **Windows 10 and Windows 11**.

## 1. Step-by-Step Installation Process

### Step 1: Download Microsoft Hindi Indic Input 3
1. Search for *"Microsoft Indic Input 3 Download"* or visit the official Bhashaindia portal / Microsoft language download archive.
2. Download the **64-bit `.zip` installer** (most modern PCs run 64-bit Windows).
3. Right-click the downloaded `.zip` file and click **Extract All**.

### Step 2: Run the Setup Installer
1. Double-click `Hindi_Indic_Input_3_64-bit.msi`.
2. Follow the setup wizard $\rightarrow$ Click **Next** $\rightarrow$ Accept License Agreement $\rightarrow$ Click **Install**.
3. Once installation completes, click **Close**.

---

## 2. Configuring Remington Gail Layout in Windows Settings

After installing the tool, you must select Remington Gail as your active keyboard layout:

1. Look at the bottom right corner of your Windows Taskbar next to the clock. You will see the language abbreviation (e.g. **`ENG`** or **`HIN`**).
2. Click on the language icon (or press `Windows Key + Spacebar`) and switch to **Hindi (India) - Hindi Indic Input 3**.
3. A small floating toolbar (Language Bar) will appear on screen.
4. Click the small **Settings / Gear Icon** on the Language Bar $\rightarrow$ Go to **Keyboards**.
5. Select **"Hindi Remington (GAIL)"**.
6. You are now ready to type in Mangal Remington Gail in MS Word, Notepad, and web browsers!

## 3. How to Fix Common Windows 10/11 Language Bar Issues

### Issue 1: Floating Language Bar is Missing
* **Fix**: Open Windows **Settings** $\rightarrow$ Go to **Time & Language** $\rightarrow$ **Typing** $\rightarrow$ **Advanced keyboard settings**.
* Check the box for **"Use the desktop language bar when it's available"**.
* Click **Language bar options** $\rightarrow$ Select **"Floating On Desktop"** or **"Docked in the taskbar"**.

### Issue 2: Switching Quickly Between English and Hindi
* Press **`Alt + Shift`** to instantly toggle between English typing and Hindi typing.
* Inside Hindi mode, press **`Ctrl + 0`** to quickly toggle the Remington Gail layout on or off.

## 4. Frequently Asked Questions (FAQ)

**Q1: Is Hindi Indic Input 3 free to download and use?**  
**Answer**: Yes, Microsoft Hindi Indic Input 3 is an official, 100% free tool provided by Microsoft for Indian language input.

**Q2: What is the difference between Remington Gail and Remington CBI in Indic Input 3?**  
**Answer**: Gail and CBI are 98% identical, but Remington Gail is the universal standard required in SSC, High Courts, and UP Police exams. Always select **Hindi Remington (GAIL)**.

**Q3: Can we practice Remington Gail typing online without installing software?**  
**Answer**: Yes! On the [Typing Nexus Practice Platform](https://typingnexus.in/practice-exams), the in-browser simulator automatically maps your English keyboard to Mangal Remington Gail without needing any software installation.

**Q4: Does Hindi Indic Input 3 support Alt codes for special characters?**  
**Answer**: Yes, all standard Alt codes (`Alt + 0216`, `Alt + 0228`, etc.) are fully supported when NumLock is ON.

**Q5: Which version should I install: 32-bit or 64-bit?**  
**Answer**: Check your Windows system type in Settings $\rightarrow$ System $\rightarrow$ About. If it says "64-bit operating system", install the 64-bit version.
