Typing in Hindi on the **Mangal Font (Remington Gail layout)** is required in almost all major government competitive exams, including **SSC (CGL, CHSL), High Courts (Allahabad, Rajasthan, Patna), State Police, and PSC exams**. While basic characters can be typed directly, complex conjunct characters (संयुक्त अक्षर), half-letters, and special symbols require **Alt Codes** using the Numeric Keypad.

Mastering these Alt codes is crucial because exam passages frequently contain words with special conjuncts (like *ह्रस्व, क्रमानुसार, द्वंद्व, मिट्टी, बुद्धि, राष्ट्र*). If you don't know the exact Alt code, you risk losing speed and accuracy.

## 2. Step-by-Step: How to Type Alt Codes on Keyboard

Follow these 4 simple steps to type Alt codes correctly during your test:

1. **Enable Num Lock**: Ensure the **Num Lock** LED light on your keyboard is turned ON.
2. **Press & Hold Left Alt**: Hold down the **Left Alt** key with your left thumb or index finger.
3. **Type the 4-Digit Code on NumPad**: Using the numeric keypad on the right side of the keyboard, type the numbers in sequence (e.g. `0`, `2`, `1`, `6` for `क्र`).
4. **Release Alt Key**: As soon as you release the Alt key, the conjunct character will instantly appear on the screen!

> **Warning**: Do NOT use the number keys above the QWERTY row for Alt codes; they only function through the dedicated numeric keypad on the right.

## 3. Alternative: Typing Half Letters & Conjuncts with Halant (्)

In modern Mangal Font Unicode engines, many conjuncts can also be created dynamically by using the **Halant (`्`)** key (`+` key or `d` key depending on layout):

* To type **क्या**: Type `क` + `्` (Halant) + `य` + `ा`
* To type **स्थान**: Type `स` + `्` (Halant) + `थ` + `ा` + `न`
* To type **ट्रक**: Type `ट` + `्` (Halant) + `र` + `क`

However, traditional examiners and software (especially in High Courts and Police tests) frequently test direct **Alt Code characters**. Practicing both methods ensures 100% readiness.

## 5. Frequently Asked Questions (FAQ)

**Q1: What is the Alt code for 'क्र' in Mangal Remington Gail?**  
**Answer**: The Alt code for **क्र** is `Alt + 0216`. Hold the left Alt key, type `0216` on the numeric keypad, and release Alt.

**Q2: What is the Alt code for 'द्ध' and 'द्व'?**  
**Answer**: The Alt code for **द्ध** is `Alt + 0228` (as in *बुद्धि*), and the Alt code for **द्व** is `Alt + 0224` (as in *द्वार*).

**Q3: Can we type Alt codes on laptops without a separate numeric keypad?**  
**Answer**: Laptops without a dedicated physical NumPad cannot execute Alt codes directly unless using Fn + NumPad overlays. For government exam preparation, always practice on a standard full-size desktop keyboard.

**Q4: Is Mangal font Remington Gail layout identical to KrutiDev 010?**  
**Answer**: Yes, approximately 95% of key positions in Remington Gail are identical to KrutiDev 010, but Remington Gail outputs standard Unicode characters with automatic matra positioning.
