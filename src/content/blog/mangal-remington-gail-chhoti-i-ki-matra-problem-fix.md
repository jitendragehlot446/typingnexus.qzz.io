## 1. Why Does the Chhoti 'i' Glitch Happen?

In the old legacy font **KrutiDev 010**, letters were simply mapped to English ASCII codes. When you typed `f` + `k`, the screen simply printed the image of `f` followed by `k`.

However, **Mangal Font is a Unicode Standard Font**:
* Unicode requires text to be stored in the linguistic logical order (Consonant + Matra).
* When using **Hindi Indic Input 3 (Remington Gail)**, the software visually allows you to press `f` (ि) first, and then as soon as you press `k` (क), the Unicode input engine automatically merges them into `"कि"`.
* If your text editor or browser does not have **Complex Script / Indic Text Rendering** enabled, the matra fails to combine and appears disconnected!

## 2. Step-by-Step Fix in MS Word & Windows

### Fix 1: Enable Unicode Complex Text in MS Word
1. Open **MS Word**.
2. Go to **File → Options → Advanced**.
3. Scroll down to the **"Show document content"** section.
4. Set **Numeral** to **System** or **Hindi**.
5. Ensure the font selected is **Mangal** (or *Aparajita / Nirmala UI*), NOT a non-Unicode font like Times New Roman.

### Fix 2: Configure Microsoft Hindi Indic Input 3 Settings
1. On the floating Language Bar, click the small **Settings / Gear Icon**.
2. Go to **Settings → Advanced**.
3. Check the box for **"Enable Visual Order for Remington GAIL"**.
4. Click **OK** and restart your application.
